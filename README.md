# Bandeja Lab · padel coaching Bangkok (concept site)

A single-page, interactive concept site for a padel coaching business in Bangkok.

- Playable top-down court mini game in the hero (padel scoring, golden point, glass rule)
- 3D shot library built with Three.js: bandeja, víbora, bajada, chiquita, globo, por tres, por cuatro, with broadcast, side, rival and ball-cam views
- Level finder on the 0–7 scale with skill ceilings, likely range, biggest gap and a level ladder
- Booking flow that prepares a LINE message

Everything is in `index.html`. No build step. Three.js loads from cdnjs.

The brand, coaches, prices and LINE ID are placeholders.
